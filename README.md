# صوتك مسموع!

موقع مستقل لمبادرة **صوتك مسموع!** من المجلس الطلابي لكلية علوم الحاسب وتقنية المعلومات، جامعة الإمام عبدالرحمن بن فيصل.

يستقبل اقتراحات الطلاب وملاحظاتهم ومشاكلهم، ويعطي فريق المجلس لوحة تحكم لمتابعتها، ويعرض إحصائيات عامة للجميع.

## الصفحات
| الصفحة | الملف | المحتوى |
|---|---|---|
| الرئيسية | `public/index.html` | تعريف قصير بالمبادرة، وبطاقات توديك لباقي الصفحات |
| شارك الآن | `public/share.html` | نموذج المشاركة |
| عن المبادرة | `public/about.html` | وش تقدر تشاركنا، وكيف تعمل المبادرة |
| الأسئلة الشائعة | `public/faq.html` | أسئلة وأجوبة عن المبادرة |
| تم الإرسال | `public/thanks.html` | تأكيد الإرسال مع الرقم المرجعي للمشاركة (مثل `SM-4K7Q2D`) |
| الإحصائيات | `public/stats.html` | عدد المشاركات وما تم حله، وتوزيعها حسب النوع والمجال والشهر، بدون بيانات شخصية |
| لوحة التحكم | `public/admin.html` | للفريق فقط بكلمة سر: عرض المشاركات وصورها، وتغيير الحالة، وملاحظات داخلية، وحذف، وتصدير إلى Excel |

حالات المشاركة: جديدة، قيد المراجعة، قيد التنفيذ، تم الحل، مغلقة.

## كيف يشتغل
- موقع ثابت (HTML و CSS و JavaScript) بدون أي خطوة بناء.
- ثلاث دوال في `netlify/functions/`:
  - `submit.mjs` ← `/api/submit`: تتحقق من المشاركة على السيرفر وتحفظها مع صورها.
  - `stats.mjs` ← `/api/stats`: أرقام عامة فقط.
  - `admin.mjs` ← `/api/admin`: لوحة التحكم، وتحتاج كلمة السر.
- التخزين في **Netlify Blobs**، فما يحتاج قاعدة بيانات خارجية.
- الحماية من الإزعاج: خانة مخفية للبوتات، ورفض النموذج إذا أُرسل خلال أقل من 3 ثوانٍ، وحد 10 مشاركات في الساعة من نفس الجهاز.

## النشر على Netlify (مرة واحدة)
1. في Netlify: **Add new project ← Import an existing project ← GitHub**، واختر هذا المستودع.
   الإعدادات تُقرأ تلقائيًا من `netlify.toml` (مجلد النشر `public`).
2. **Project configuration ← Environment variables ← Add a variable**:
   - **Key:** `ADMIN_PASSWORD`
   - **Value:** كلمة سر قوية لفريق المجلس (لا تشاركها خارج الفريق).
3. **Deploys ← Trigger deploy ← Deploy project** حتى تشتغل كلمة السر.
4. (اختياري) غيّر اسم الرابط من **Project configuration ← Change project name**، مثل `sawtak-masmoo` ليصير الرابط `sawtak-masmoo.netlify.app`.

بعدها أي تعديل يُرفع إلى فرع `main` يُنشر تلقائيًا.

## التشغيل محليًا
```bash
npm install
npx netlify-cli dev
```
وأضف `ADMIN_PASSWORD=كلمة_السر` في ملف `.env` حتى تقدر تدخل لوحة التحكم محليًا.

## التعديل
- **الألوان:** المتغيرات في أعلى `public/assets/style.css`.
- **النصوص:** مباشرة في ملفات HTML داخل `public/`.
- **خيارات النموذج:** في `public/share.html`، **وعدّلها أيضًا** في `netlify/lib/shared.mjs` (قائمة `CHOICES`)، لأن السيرفر يرفض أي قيمة غير موجودة فيها.
- **حالات المشاركة:** في `STATUSES` داخل `netlify/lib/shared.mjs`.
